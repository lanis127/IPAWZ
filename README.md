# IPAWZ 🐾


## Nome do Projeto 🐶
Uma plataforma web pensada para conectar pessoas, ONGs e animais, facilitando processos de adoção, doação, voluntariado.

### 📖 Sobre o projeto
Este projeto foi desenvolvido como extensão do curso de GTI e tem como objetivo utilizar a tecnologia para incentivar a adoção responsável, promover campanhas de doação e aproximar voluntários de instituições de proteção animal. <br>
A  plataforma reúne, em um único ambiente, funcionalidades que facilitam o contato entre a comunidade e organizações dedicadas ao bem-estar animal.

### 🎯 Objetivo 
Contribuir para aumentar a visibilidade de animais disponíveis para adoção e facilitar o apoio às instituições de proteção animal por meio da tecnologia.

### Funcionalidadeds
- 🐱 Cadastro de pets para adoção
- ❤ Solicitação de adoção
- 💰 Doações para instituições
- 🙋‍♀️ Cadastro de voluntários
- 🏢 Perfil de ONGs e usuários
- 📱 Interface responsiva
